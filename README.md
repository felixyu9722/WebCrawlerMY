## 🌟 Key Features / 核心特性

### 🇬🇧 English
* **🕷️ Cyber-Mechanical Spider (IK Walking Gait)**: 8-legged inverse kinematics procedural animation with natural biomechanical locomotion, respiratory breathing rhythm, dynamic eye headlight cones, and autonomous exploration.
* **🚀 Cyber START Launch Screen**: Fullscreen cyberpunk overlay modal that safely initializes the audio engine and system upon user interaction, 100% compliant with browser autoplay policies.
* **🧹 Web Cleanup & Celebration Dance (20 Items)**: When the web accumulates 20 prey items/data capsules, the spider rushes back at 2.4x speed, detonates multi-color cyber fireworks, cleans all items from the web, and performs a 360° celebration dance with rainbow eyes and particle confetti!
* **🕸️ High-Definition Holographic Web**: Multi-layered spider web featuring a nebula aura backdrop, dual-layer high-contrast neon lines, glistening dew nodes at spoke intersections, organic catenary droop curves, and expanding energy scan waves.
* **📱 Mobile-Native Floating Dock**: Compact bottom-right trigger pills (`[ 🎵 Music ]` and `[ 🌐 Radar ]`) that pop up upwards and are mutually exclusive (never overlap or clutter mobile screen).
* **🌐 Holographic Star Map Radar**: Floating 360° radar sweep HUD anchored at the viewport corner with real-time target scanning and click-to-dispatch navigation.
* **🎵 Ambient Cyber Audio ("Arachnid Pulse")**: Built-in procedural Web Audio synthesizer with smooth fade-in, visualizer wave bars, and interactive volume control.
* **🪰 Digital Insect Ecosystem & Hunt AI**: Auto-spawning digital prey with evasion AI; insects completely enter the viewport before spider triggers red-eye pursuit and pounce.
* **🎭 Cinematic Acrobatics**: Dynamic jumpscare screen leaps and full-page silk rappelling drops accurately landing at the page footer at 1.5x drop speed.

### 🇨🇳 中文
* **🕷️ 拟物化机械智能大蜘蛛**：8 肢精准反向运动学（IK）行走步态、呼吸律动、双重前置探照光锥、触角探测与自主漫游。
* **🚀 赛博风 START 启动确认系统**：页面加载时居中显示赛博启动弹窗，点击 `[ ▶ START ]` 或回车后立即以合法手势无缝解锁并开启背景音乐与音频引擎。
* **🧹 蛛网满 20 件大扫除与狂欢跳舞**：蛛网储存达到 20 件数据食物时，蜘蛛以 2.4 倍极速狂奔回巢，触发多重数码赛博烟花大爆炸，清空所有垃圾并展开约 3.6 秒的狂欢跳舞（欢快 360° 自转、肢足踩踏律动、彩灯派对复眼、周围彩花烟火、弹性蛛网晃动）。
* **🕸️ 顶部高清晰全息光网**：专属星云背光光晕（Nebula Aura Backdrop）、双层高对比度高亮丝线、每个交汇点闪烁数码露珠（全息光节点）、真实蛛丝下垂微弧度（Catenary Droop）与 3.5 秒周期性全息能量脉冲波。
* **📱 手机端右下角微型胶囊栏**：右下角常驻微型双胶囊 `[ 🎵 音乐 ]` 与 `[ 🌐 雷达 ]`，点击单独向上展开，**互斥切换、绝不重叠**，点击外部或 `✕` 快速收起。
* **🌐 全息星图雷达 (Radar)**：固定悬浮于屏幕右下角，随视口流畅游走，支持 360° 连续波束扫描与星图点击调度。
* **🎵 Arachnid Pulse 原创氛围背景音乐**：左下角音量与播放控制器，智能无缝唤醒，动态音频律动跳动。
* **🪰 数码飞虫生态与红眼暴走追捕**：飞虫完全飞入画面视界后触发警报，蜘蛛双眼暴走变红全速锁定抓捕，抓获后运回左侧蛛网收藏。
* **🎭 机械巨蛛特技演出**：扑面突脸惊悚跳跃与天顶吐长白丝全程垂落至页脚（速度提升 0.5 倍，落地精准不超界）。

## 🎮 Interactive Controls / 交互操作指南

| 操作 / Action | 效果 / Description |
| :--- | :--- |
| **点击 [ ▶ START ]** | 解锁并播放背景音乐，平滑进入赛博漫游系统 |
| **手机点击右下角胶囊** | 点击 `[ 🎵 音乐 ]` 或 `[ 🌐 雷达 ]` 独立呼出面板，互斥防重叠 |
| **点击网页中任意文字** | 机械蜘蛛将其作为优先目标前往扫描并触发赛博变异 |
| **点击雷达星图上的点** | 全息调度蜘蛛跨视口前往对应坐标点 |
| **点击左侧 [ 🕸️ 蛛网食物库 ]** | **快捷测试**：一键填满至 20 件，立即召唤蜘蛛回巢大扫除并跳舞 |
| **右上角 HUD 面板** | 切换蜘蛛品种（大眼探秘 / 狂暴黑寡妇 / 脉冲织网者）、调节尺寸与行走模式 |
