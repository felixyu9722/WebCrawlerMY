# WebCrawlerMY - 赛博全息拟物化网络爬虫

> 灵感源自 X (Twitter) 平台创意学者 [@rybinfx](https://x.com/rybinfx) 的 Web Crawlers `/[•]\` 设计，结合赛博朋克与拟物化生物动力学（IK 逆向运动学）的实验性交互网页。

## 🌟 核心特性
- **🕷️ 拟物化机械智能大蜘蛛**：8 肢精准反向运动学（IK）行走步态、呼吸律动、触角探测与自主漫游。
- **🌐 全息星图雷达 (Radar)**：固定悬浮于屏幕右下角，随视口流畅游走，支持 360° 连续波束扫描与星图调度。
- **🎵 Arachnid Pulse 原创氛围背景音乐**：左下角音量与播放控制器，开局默认 16% 音量，智能无缝唤醒。
- **🕸️ 侧边发光蛛网储食基地**：累积抓取文字药丸归巢挂存，织造动态发光能量蛛网。
- **🪰 数码飞虫生态与红眼暴走追捕**：每 30 秒或手动投喂，飞虫智能远距避让与逃窜，蜘蛛红眼锁定追猎。
- **🎭 机械巨蛛特技演出**：扑面突脸与天顶吐丝倒挂吊落。
